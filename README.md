# Avis Resto : télécharger l'application

Application Android pour rédiger et déposer rapidement des avis de restaurant : scanner de QR code,
remplissage des pages d'avis selon 👍 / 👎, historique de vos avis.

## Installer

1. Sur le téléphone Android, ouvrez ce lien (ou scannez le QR code de l'écran « Partager l'application ») :
   **[Télécharger la dernière version](https://github.com/teddymontouchet/avis-resto-apk/releases/latest/download/AvisResto.apk)**
2. Ouvrez le fichier téléchargé.
3. Android demande d'autoriser l'installation depuis le navigateur : acceptez, puis installez.

Les nouvelles versions s'installent par-dessus l'ancienne, sans perdre l'historique ni les réglages.

Toutes les versions : [Releases](https://github.com/teddymontouchet/avis-resto-apk/releases).
